# ІІ-помічник: як він працює і що дає ключ

## Без ключа (працює вже зараз)
Помічник відповідає з вбудованої бази знань (`shared/workKnowledge.js`):
14 видів робіт, довідник по техніці, різниця між нею, типові помилки, безпека, орієнтовні ціни.
Це швидко, безкоштовно й без помилок «фантазії» — він не вигадує того, чого немає в базі.

## З ключем Anthropic (розумніший)
Тоді помічник розуміє довільні формулювання, веде діалог і відповідає на нестандартні питання,
але спирається на ту саму базу знань (деталі по темі розмови додаються в запит автоматично).

1. https://console.anthropic.com → Settings → API Keys → Create Key. Скопіюйте ключ (sk-ant-...).
   У Billing одразу виставте невеликий ліміт витрат.
2. Vercel → проєкт → Settings → Environment Variables → Add:
   - Key: ANTHROPIC_API_KEY
   - Value: ваш ключ
   - Type: Secret, Environment: Production → Save
3. Deployments → останній деплой → ⋯ → Redeploy.

Приблизна ціна: кілька копійок за відповідь (модель Haiku). Ключ нікому не показуйте.

## Як доповнити базу знань
Усі види робіт і техніка — у файлі `shared/workKnowledge.js`.
Новий вид роботи додається блоком у масив JOBS (назва, ключові слова, техніка, кроки, помилки).
Зміни одразу працюють і в локальному режимі, і в запитах до ШІ.
