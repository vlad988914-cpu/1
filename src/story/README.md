# ScrollStory — «Техніка зблизька»

Сцена на всю висоту екрана, яка «залипає»: прокрутка сторінки перемотує відео, а підписи змінюють одна одну
(кадр → ковш → стріла → кабіна). Усе керується `story.config.js`.

## Як додати етап (борт, двигун, ззаду)
1. Згенеруйте наступний шматок відео (старт — останній кадр попереднього), склейте з поточним роликом
   і перекодуйте для перемотки (часті ключові кадри):
   ```
   ffmpeg -i joined.mp4 -an -vf scale=576:1012 -c:v libx264 -crf 27 -g 6 -keyint_min 6 -sc_threshold 0 -pix_fmt yuv420p -movflags +faststart public/story/excavator-scrub.mp4
   ffmpeg -i joined.mp4 -an -vf scale=576:1012 -c:v libvpx-vp9 -b:v 0 -crf 40 -g 8 public/story/excavator-scrub.webm
   ```
2. У `story.config.js` оновіть `video.duration`, додайте опори в `stops` (прогрес → секунда відео; однакові секунди поспіль = пауза)
   та новий запис у `stages` (діапазони `range` мають стикуватися). Перевірка: `npm test`.

## Важливо
* Сервер має віддавати відео з підтримкою HTTP Range (Vercel підтримує). Без цього браузер не вміє перемотувати.
* Відео без звуку (`muted`, `playsInline`), ніколи не відтворюється — лише перемотується.
* `prefers-reduced-motion`: без липкого екрана й перемотки, звичайний блок з постером і списком етапів.
* Якщо відео не завантажилось — показується постер, підписи працюють.
