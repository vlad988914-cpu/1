# ExcavatorHero — інтерактивний герой на одному зображенні

Одне 2D-зображення стає «майже 3D»: камера плавно під'їжджає до деталі, решта затемнюється, деталь підсвічується,
з'являється скляна підказка. Усе керується даними — додати чи змінити зону можна без правок коду компонента.

```jsx
import ExcavatorHero from "./hero/ExcavatorHero.jsx";

<ExcavatorHero
  onSelectHotspot={(h) => openCatalog(h.catalog.type)}   // клік/кнопка в панелі
  resolveHotspot={(h) => ({ data: { stats: [{ label: "в каталозі", value: count[h.catalog.type] }] } })}
  ctaLabel="Підібрати техніку"
>
  …заголовок, пошук, кнопки…
</ExcavatorHero>
```

## Файли
| файл | призначення |
|---|---|
| `hotspots.config.js` | зображення (`heroImage`) і всі зони (`hotspots`) |
| `ExcavatorHero.jsx` | компонент: камера (пружини), паралакс, наведення/дотик/клавіатура |
| `effects.jsx` | ефекти зон (`dig`, `hydraulics`, `boom`, `cab`, `wheels`, `engine`) + `Highlight`, `ClippedSweep` |
| `Sprite.jsx` | вирізає контур із зображення в окремий canvas-шар |
| `HotspotPanel.jsx` | панель-підказка (біля деталі / знизу на дотик) і маркери |
| `Particles.jsx` | пил у повітрі та хмарки від ковша/коліс |
| `geometry.js`, `camera.js` | чиста математика (тестується: `npm test`) |
| `hero.css` | стилі (префікс `hx-`; анімуються лише `transform` і `opacity`) |

## Як налаштувати зону (`hotspots.config.js`)
Усі координати — у пікселях **оригінального** зображення (зараз 720 × 1264). Якщо замінити картинку на більшу
(наприклад 1440 × 2528), змініть `width/height` і помножте координати на 2.

```js
{
  id: "bucket",            // унікальний ключ
  order: 1,                // порядок для клавіатури
  label: "КОВШ",
  description: "Розробка ґрунту",
  shapes: [[[x, y], …]],   // один або кілька контурів: по ним працюють наведення і підсвітка
  anchor: { x, y },        // куди «прив'язана» підказка і маркер
  tooltip: { side: "left" | "right", gap: 26 },
  camera: { x, y, zoom },  // куди летить камера
  effect: "dig",           // ключ ефекту; null — лише підсвітка
  effectOptions: { … },    // параметри ефекту (рухомі контури, точка обертання…)
  highlight: { brightness: 1.2, dim: 0.52 },
  hitMargin: 8,            // допуск наведення (px) для тонких деталей
  catalog: { type: "Екскаватор" },   // зв'язок з каталогом: тип техніки
  data: {},                // довільні дані; їх можна підмішати через resolveHotspot
}
```

## Підключення до реальних даних
* `onSelectHotspot(hotspot)` — клік по деталі або кнопка «Підібрати техніку» в панелі.
* `resolveHotspot(hotspot)` — повертає частину полів, що підмішується в панель; `data.stats = [{label, value}]`
  показується чіпами (кількість оголошень, ціна від…).

## Власний ефект
```jsx
const Glow = ({ ctx }) => <Highlight ctx={ctx} filter="brightness(1.4)" />;
<ExcavatorHero effects={{ glow: Glow }} config={{ image, hotspots: [{ …, effect: "glow" }] }} />
```
`ctx = { hotspot, active, image, imageSize, size: { worldW, worldH }, reduced }`.

## Ковш як окремий шар
Зона з `effectOptions.cutout: true` вирізається з основи: `heroImage.plate` — те саме фото без ковша
(небо за ним відновлено), а сам ковш — оригінальні пікселі в окремому canvas-шарі. У спокої картинка ідентична
оригіналу; при русі «привида» на старому місці немає.

## Поведінка
* **Десктоп:** наведення → камера, затемнення, підсвітка, панель біля деталі. «Липка» зона та затримки входу/виходу
  прибирають мигання при зумі.
* **Телефон/планшет:** тап по деталі відкриває її, повторний тап або тап повз — закриває; панель стоїть знизу кадру,
  підказки-точки видно одразу.
* **Клавіатура / скрінрідер:** кожна деталь — окрема кнопка (`Tab`), `Esc` закриває.
* `prefers-reduced-motion`: без паралаксу, дрейфу, пилу й вступного зуму; камера рухається коротким твіном.
