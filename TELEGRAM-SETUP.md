# Підключення Telegram: нові заявки приходять вам у месенджер

## Крок 1. Створіть бота (2 хв)
1. У Telegram відкрийте @BotFather → надішліть /newbot
2. Придумайте назву (напр. ТехМайданчик Заявки) і username, що закінчується на bot
3. BotFather пришле ТОКЕН вигляду 123456789:AAH... — це пароль до бота, нікому його не показуйте

## Крок 2. Дізнайтесь свій chat id (1 хв)
1. Відкрийте свого нового бота і натисніть Start (обов'язково! інакше бот не зможе вам писати)
2. Відкрийте @userinfobot → Start → він покаже ваш Id (число, напр. 123456789)

## Крок 3. Додайте змінні у Vercel (2 хв)
Vercel → проєкт → Settings → Environment Variables:
- TELEGRAM_BOT_TOKEN = токен з кроку 1
- TELEGRAM_CHAT_ID   = число з кроку 2
Environments: Production → Save

## Крок 4. Завантажте оновлення і перезапустіть
1. Скопіюйте файли з website.zip у папку репозиторію (з'явилась папка api/ з файлом notify.js)
2. GitHub Desktop → Commit → Push origin
3. Vercel → Deployments → Redeploy

## Перевірка
Відкрийте сайт → «Залишити заявку» → заповніть → надішліть. Через 1-2 секунди повідомлення прийде в Telegram.

## Важливо
- Це односторонні сповіщення: заявка → вам у Telegram.
- Керування заявками кнопками з Telegram (розсилка власникам, прийняти/відмовити) — це наступний етап: повний бот з папки bot/ + база Supabase.
- Якщо хтось знайде адресу /api/notify, він зможе слати вам сміттєві заявки. Це вирішується на наступному етапі (база + перевірка).
