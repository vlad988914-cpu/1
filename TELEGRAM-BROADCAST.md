# Розсилка через Telegram-бота

## Один раз налаштувати
1. Supabase → SQL Editor → вставте вміст файлу `db/telegram-subs.sql` → Run.
2. Завантажте оновлення сайту (GitHub Desktop → Commit → Push), дочекайтесь деплою Vercel.
3. Перереєструйте webhook (щоб бот отримував натискання кнопок). Відкрийте в браузері:
   `https://www.tehmaydan.com/api/tg-webhook?setup=ВАШ_TG_WEBHOOK_SECRET`
   Має з'явитися `{"ok":true,...}`.

## Як люди підписуються
- Вони відкривають бота і пишуть /subscribe → обирають «Я власник техніки» або «Я шукаю техніку».
- Відписка: /stop. Пишуть лише тим, хто підписався сам. Холодна розсилка по чужих номерах в Telegram через бота неможлива.
- Посилання для запрошення: `https://t.me/ІМ'Я_ВАШОГО_БОТА?start=sub` (людина натискає Start, а потім /subscribe).

## Як робити розсилку (тільки ви, з вашого акаунта Telegram)
У чаті з ботом:
- `/stats` — скільки підписників у кожній групі
- `/broadcast owners Текст` — власникам техніки
- `/broadcast clients Текст` — клієнтам
- `/broadcast all Текст` — усім

Обмеження: за один раз до 200 підписників (ліміт часу Vercel). Тим, хто заблокував бота, розсилка вимикається автоматично.
